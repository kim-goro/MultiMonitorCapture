# 보안 요구사항 체크리스트 (Security Checklist)

대상 스택: C# / WinForms / .NET Framework 4.0 / WinXP·10·11 / 오프라인 설비PC
점검 시점: 큰 업데이트(메이저/마이너)마다 전 항목 재점검.
참고: OWASP(웹 항목은 비적용 표시), CWE, 데스크톱 앱 보안 원칙.

각 항목 상태: [ ] 미확인 / [x] 통과 / [!] 위험(조치필요)

---

## A. 최소 권한 (Least Privilege)

- [ ] A-1 매니페스트 requestedExecutionLevel = asInvoker (관리자 권한 요구 금지)
- [ ] A-2 관리자 전용 API 미사용. 표준 사용자 권한으로 전 기능 동작
- [ ] A-3 시스템 설정 변경은 사용자가 명시적으로 실행하는 "주 모니터 변경"(FR-6) 한 가지로 한정.
        그 외 전역 설정/레지스트리 은밀 변경 없음. 변경 실패 시 원상 유지 및 안전 안내.
- [ ] A-4 레지스트리 쓰기 없음(읽기도 최소화). 자동 시작 등록 등 은밀 동작 없음
- [ ] A-5 쓰기는 %LOCALAPPDATA% 하위로 제한(Program Files/시스템 폴더 쓰기 금지)

## B. 공격 표면 최소화 (Attack Surface)

- [ ] B-1 네트워크 통신 코드 전무(소켓/HTTP/DNS 미사용) — 오프라인 원칙
- [ ] B-2 서드파티 의존성 0개(또는 승인된 최소). 공급망 위험 차단
- [ ] B-3 동적 코드 실행 없음(Assembly.Load, Reflection 기반 실행, CodeDom 등 미사용)
- [ ] B-4 외부 프로세스 실행(Process.Start) 없음. 부득이 시 인자 화이트리스트
- [ ] B-5 전역 훅(SetWindowsHookEx) 미사용 — 입력 가로채기/충돌/오탐 위험 회피
- [ ] B-6 IPC/명명 파이프/공유 메모리 미사용(단일 프로세스 완결)

## C. 입력/역직렬화 안전 (Input & Deserialization)

- [ ] C-1 설정 파일은 단순 INI(키=값)로 파싱. BinaryFormatter/SoapFormatter 금지(CWE-502)
- [ ] C-2 설정 값 범위 검증(FPS, 시간, 인덱스 등)과 기본값 폴백. 손상 파일에도 안전 기동
- [ ] C-3 파일 경로 조합 시 경로 조작 방지(Path.Combine + 화이트리스트, .. 차단)
- [ ] C-4 모니터/화면 좌표 등 외부 상태 값 유효성 검증(음수/과대값 방어)

## D. 자원/가용성 (Resource & DoS Self-protection)

- [ ] D-1 모든 GDI 자원(Bitmap/Graphics/HDC/HBITMAP) 확정 해제 — 핸들 누수 0
- [ ] D-2 캡처 FPS 상한 및 기본 저프레임으로 CPU 과부하 방지(설비 작업 비방해)
- [ ] D-3 스레드/타이머/NotifyIcon 종료 시 정리. 좀비 스레드 없음
- [ ] D-4 24시간 연속 구동 시 메모리/핸들 증가 없음(장시간 테스트)
- [ ] D-5 단일 인스턴스 Mutex 로 중복 실행 부하 차단

## E. 안정성/격리 (Stability & Isolation)

- [ ] E-1 전역 예외 처리기(Application.ThreadException, AppDomain.UnhandledException) 등록
- [ ] E-2 예외로 인해 프로그램/PC 다운 없음. 개별 타일 실패는 격리 후 재시도
- [ ] E-3 다른 프로그램의 창/입력/파일을 변경하지 않음(읽기 전용 화면 캡처)
- [ ] E-4 파일/자원 임의 삭제·수정 없음. 자체 설정 파일만 관리
- [ ] E-5 종료 시 트레이 아이콘/자원 정상 정리(잔존 아이콘 없음)

## F. 데이터 보호 (Sensitive Data)

- [ ] F-1 캡처 영상은 로컬 메모리에만 존재. 디스크 저장/전송 없음(기본)
- [ ] F-2 캡처 이미지 임시파일 미생성. 클립보드 자동 복사 없음
- [ ] F-3 로그에 화면 내용/민감정보 미기록(경로/스택 수준으로 제한)
- [ ] F-4 About 화면에 취급 주의 문구 표시(화면 캡처 특성 고지)

## G. 무결성/배포 (Integrity & Supply Chain)

- [ ] G-1 릴리스 빌드 산출물(exe) 해시 기록 및 배포처와 대조
- [ ] G-2 (가능 시) 코드 서명. 오프라인이면 최소한 배포 매체 무결성 관리
- [ ] G-3 빌드 재현성: 고정된 SDK/컴파일러/버전으로 빌드 절차 문서화
- [ ] G-4 소스 버전 태깅과 변경 이력 관리(버전-수정일 표시와 일치)

## H. 로깅/진단 (Logging)

- [ ] H-1 오류 로그는 %LOCALAPPDATA% 하위, 크기 상한/로테이션 적용
- [ ] H-2 로그에 개인정보/화면 캡처 데이터 미포함
- [ ] H-3 예외 로깅 시 사용자에게는 안전한 메시지만 표시

## I. 플랫폼별 유의 (XP/10/11)

- [ ] I-1 XP 미지원 API(DXGI Desktop Duplication, per-monitor DPI 등) 미사용
- [ ] I-2 P/Invoke 는 NativeMethods 한 곳에 격리, SetLastError 처리 및 실패 검사
- [ ] I-3 DPI 스케일에서 좌표/오버레이 렌더 정합성 확인(10/11 고배율)
- [ ] I-4 OS별 캡처 정상 동작 확인(다중 모니터, 음수 좌표 배치 포함)
