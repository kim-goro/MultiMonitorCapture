# 릴리스 전 점검 체크리스트 (Pre-Release Checklist)

목적: 태그를 붙이고 GitHub Releases 에 exe 를 올리기 직전에 수행하는 최종 관문.
사용법: 릴리스마다 이 문서를 복사해 체크하고, 하단 기록표에 결과를 남긴다.
관련: docs/03_보안요구사항체크리스트.md (설계/구현 수준 점검, 큰 업데이트마다)
      본 문서는 배포 직전 실무 점검(공개 노출 위주)에 집중한다.

상태 표기: [ ] 미확인 / [x] 통과 / [!] 위험(릴리스 중단)

---

## A. 비밀정보 및 평문 노출 점검 (최우선, 하나라도 걸리면 릴리스 중단)

공개 저장소는 되돌릴 수 없다. push 이전에 반드시 수행한다.

- [ ] A-1 하드코딩된 비밀번호/키/토큰 없음
      검사: 아래 명령으로 소스와 문서를 훑는다
      git grep -n -i -E "password|passwd|pwd|secret|api[_-]?key|token|credential|private[_-]?key"
- [ ] A-2 접속 정보(IP, 호스트명, 포트, 사내 도메인) 노출 없음
      검사: git grep -n -E "([0-9]{1,3}\.){3}[0-9]{1,3}|\.local\b|\.corp\b|\.lan\b"
- [ ] A-3 개인정보(이메일, 전화번호, 사번, 실명 목록) 노출 없음
      검사: git grep -n -E "[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}"
      허용: 공개 의도가 있는 개발자 연락처만
- [ ] A-4 인증서/키 파일 미포함 (.pfx, .snk, .pem, .key, .p12)
      검사: git ls-files | grep -Ei "\.(pfx|snk|pem|key|p12|jks)$"
- [ ] A-5 사내 문서/캡처 이미지에 민감 화면 미포함
      화면 캡처 도구 특성상 스크린샷에 업무 화면이 찍히지 않았는지 눈으로 확인
- [ ] A-6 AI 도구 개인 설정 미추적 (.claude/settings.local.json 등)
      검사: git ls-files | grep -E "\.local\.json$"  결과가 없어야 정상
- [ ] A-7 커밋 이력에도 비밀정보 없음 (과거 커밋 포함)
      검사: git log -p | grep -n -i -E "password|secret|api[_-]?key|token"
      주의: 이력에 남았다면 파일 삭제만으로는 부족하다. 이력 재작성 또는 키 폐기 필요.

## B. 저장소 위생 (Repository Hygiene)

- [ ] B-1 빌드 산출물 미추적 (bin/, obj/, *.exe, *.pdb)
      검사: git ls-files | grep -Ei "(^|/)(bin|obj)/|\.(exe|pdb)$"  결과 없어야 정상
- [ ] B-2 .gitignore 가 의도대로 동작
      검사: git status --porcelain 에 불필요 파일이 뜨지 않는지 확인
- [ ] B-3 저장소 구조가 중첩되지 않음(프로젝트 루트 = 저장소 루트)
- [ ] B-4 LICENSE 존재 및 내용 정확(MIT, 저작권자 표기 일치)
- [ ] B-5 README 의 사용법/호환 OS/주의사항이 현재 버전과 일치

## C. 버전 및 표기 일관성

- [ ] C-1 src/Properties/AppMetadata.cs 의 Version 갱신
- [ ] C-2 AppMetadata.cs 의 BuildDate 를 릴리스 당일로 갱신
- [ ] C-3 git 태그(vX.Y.Z)와 AppMetadata.Version 일치
- [ ] C-4 exe 속성의 버전/회사명 확인
      검사: (Get-Item .\MultiMonitorCapture.exe).VersionInfo
- [ ] C-5 실행 후 제목표시줄과 정보 보기 창의 표기가 릴리스 내용과 일치

## D. 빌드 및 산출물 검증

- [ ] D-1 Release 구성으로 클린 빌드 성공, 경고 0 / 오류 0
      명령: dotnet build src/MultiMonitorCapture.csproj -c Release
- [ ] D-2 산출물이 단일 exe (런타임 종속 DLL 동봉 없음)
- [ ] D-3 exe 실행 시 정상 기동 및 정상 종료(트레이 아이콘 잔존 없음)
- [ ] D-4 SHA-256 해시 산출 및 릴리스 노트에 기재
      명령: Get-FileHash .\MultiMonitorCapture.exe -Algorithm SHA256
- [ ] D-5 (XP 배포 시) .NET Framework 4.0 참조 어셈블리 기준 빌드로 4.0 표면만 사용했는지 확인

## E. 동작 확인 (핵심 기능 회귀)

- [ ] E-1 다중 모니터 환경에서 격자 캡처 정상 표시
- [ ] E-2 마우스 호버 시 노란 테두리, 클릭 시 노란 원 표시
- [ ] E-3 컨트롤창 닫기 시 종료되지 않고 트레이 상주
- [ ] E-4 트레이 메뉴 5개 항목 정상 동작(정보/컨트롤창/주모니터/백그라운드/종료)
- [ ] E-5 주 모니터 변경 후 격자 재구성 정상
- [ ] E-6 장시간 구동 시 핸들/메모리 증가 없음

## F. 공개 배포 절차

- [ ] F-1 저장소 공개 범위 확인(Public 여부 의도와 일치)
- [ ] F-2 태그 생성 및 푸시(vX.Y.Z)
- [ ] F-3 릴리스 노트 작성(변경 내역, 지원 OS, 실행 요구사항, SHA-256, 취급 주의)
- [ ] F-4 exe 를 Release 자산으로 첨부(저장소 커밋 아님)
- [ ] F-5 미서명 배포 안내(SmartScreen 경고 가능성과 해시 확인 방법 명시)

## 자동 점검 명령 모음

아래를 릴리스 직전에 한 번에 실행하여 A/B 항목을 빠르게 훑는다.

PowerShell 기준:

```
# A-1 비밀정보 키워드
git grep -n -i -E "password|passwd|secret|api[_-]?key|token|credential"

# A-3 이메일
git grep -n -E "[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}"

# A-4 / A-6 / B-1 추적되면 안 되는 파일
git ls-files | Select-String -Pattern "\.(pfx|snk|pem|key|p12)$|\.local\.json$|(^|/)(bin|obj)/|\.(exe|pdb)$"

# B-2 작업 트리 청결
git status --porcelain

# D-4 해시
Get-FileHash .\src\bin\Release\MultiMonitorCapture.exe -Algorithm SHA256
```

기대 결과: 위 명령들이 아무것도 출력하지 않아야 정상(해시 제외).
