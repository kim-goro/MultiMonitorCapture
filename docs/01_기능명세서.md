# 기능 명세서 (Functional Specification)

프로그램명: 멀티모니터캡처 (표시명, 한글)
솔루션/코드명: MultiMonitorCapture (영문, 파일/네임스페이스용)
버전 체계: Major.Minor.Patch (예: 1.0.0)
문서 대상: WinForms / .NET Framework 4.0 / WinXP·10·11

---

## 0. 용어 정의

- 컨트롤창(ControlForm): 프로그램의 메인 창. 캡처 타일들을 격자로 담는다.
- 캡처 타일(CaptureTile): 모니터 1개의 화면을 실시간 표시하는 재사용 UserControl.
- 주(기준) 모니터: 캡처 대상에서 제외되는 모니터. 기본은 OS 주 모니터.
- 트레이 아이콘(TrayComponent): 시스템 알림 영역 아이콘 + 우클릭 메뉴.

---

## 1. 실행 및 초기화

- FR-1.1 프로그램 실행 시 컨트롤창과 트레이 아이콘을 생성한다.
- FR-1.2 컨트롤창 제목표시줄에 다음을 표시한다.
  - 형식: "멀티모니터캡처 v{버전} (수정일 {yyyy-MM-dd})"
  - 버전은 어셈블리 버전에서, 수정일은 빌드 시각(또는 빌드 상수)에서 읽는다.
- FR-1.3 동일 프로그램의 2중 실행을 Mutex 로 차단한다. 이미 실행 중이면 기존 컨트롤창을 앞으로 가져온다.
- FR-1.4 전역 예외 처리기를 등록하여 어떤 예외도 프로그램/PC 를 다운시키지 않는다.

## 2. 다중 모니터 격자 캡처

- FR-2.1 System.Windows.Forms.Screen.AllScreens 로 모니터를 열거한다.
- FR-2.2 주(기준) 모니터를 제외한 나머지 모니터 수만큼 캡처 타일을 생성한다.
- FR-2.3 타일은 컨트롤창 안에 격자(Grid) 레이아웃으로 배치한다.
  - 타일 개수 N 에 대해 열 수 = ceil(sqrt(N)), 행 수 = ceil(N / 열 수)
  - TableLayoutPanel 로 균등 배치, 각 타일은 원본 비율 유지(레터박스)로 축소 표시
- FR-2.4 캡처는 GDI BitBlt 로 각 모니터의 Bounds 영역을 취득한다.
- FR-2.5 캡처 주기는 설정값(기본 5 FPS = 200ms). 설비PC 과부하 방지를 위해 저프레임 기본값 사용.
  - 캡처는 백그라운드 스레드에서 수행하고, 화면 반영만 UI 스레드로 마샬링한다.
  - 이전 프레임 Bitmap 은 즉시 Dispose 하여 GDI 핸들 누수를 방지한다.
- FR-2.6 모니터 구성이 변경되면(SystemEvents.DisplaySettingsChanged) 타일을 재구성한다.
- FR-2.7 창 바탕(빈 영역) 우클릭 시 컨텍스트 메뉴에 "주(기준) 모니터 설정" 항목을 제공한다.
  - 구현 가능 여부: 가능. ControlForm 의 빈 영역 또는 각 타일의 컨텍스트 메뉴로 제공.
  - 동작 옵션은 FR-6 참조(앱 내부 지정 기본, OS 변경은 확인 후).

## 3. 캡처 타일 표시 요소

- FR-3.1 타일 좌측 상단에 모니터 번호를 오버레이로 표시한다(예: "1", "2").
  - 번호는 열거 순서 기반의 안정적 인덱스를 부여한다.
- FR-3.2 타일 하단 레이아웃(바)에 모니터 이름과 설정 버튼 "..." 을 표시한다.
  - 모니터 이름: 기본은 Screen.DeviceName 표기(확정). 사용자 별칭은 향후 확장.
  - "..." 버튼 클릭 시 해당 모니터 설정 팝업(해상도/좌표 등 정보, 향후 별칭 변경)을 연다.
- FR-3.3 오버레이 텍스트는 가독성을 위해 반투명 배경 + 대비색으로 그린다.

## 4. 마우스 호버 강조

- FR-4.1 마우스 포인터가 위치한 캡처 타일의 테두리를 노란색으로 표시한다.
- FR-4.2 타일의 MouseEnter 에서 강조 on, MouseLeave 에서 off (앱 자체 컨트롤의 로컬 이벤트만 사용).
  - 전역 마우스 훅(SetWindowsHookEx) 은 사용하지 않는다(성능/충돌/보안 위험 회피).
- FR-4.3 동시에 강조되는 타일은 최대 1개(가장 최근 진입 타일).

## 5. 마우스 클릭 표시

- FR-5.1 컨트롤창 내부의 캡처 타일 안에서 마우스 클릭 시, 클릭 지점에 노란색 원을 일시 표시한다.
- FR-5.2 표시 시간은 설정값(기본 400ms) 후 자동 소멸(Timer 기반 페이드/제거).
- FR-5.3 타일 밖(컨트롤창 외부, 다른 프로그램)에서는 표시하지 않는다(로컬 MouseDown 만 처리).
- FR-5.4 원은 캡처 영상 위 오버레이 레이어에 그려지며 캡처 원본 데이터는 변경하지 않는다.

## 6. 주 모니터 설정  (확정: OS 주 모니터 실제 변경)

- FR-6.1 동작: Windows 디스플레이 설정과 동일하게 OS 주 모니터를 실제로 변경한다.
  - 구현: ChangeDisplaySettingsEx(대상 장치, CDS_SET_PRIMARY | CDS_UPDATEREGISTRY).
    나머지 장치 좌표를 대상 기준으로 재계산하여 함께 적용한다(Windows 설정창과 동일 결과).
  - 관리자 권한 불필요(사용자별 디스플레이 설정). XP/10/11 공통 지원 API.
  - 사용자가 명시적으로 실행하는 승인된 동작이므로 별도 강제 확인창 없이 즉시 적용한다.
    (선택) 안전을 위해 실패/미지원 시에는 원상 유지하고 안전한 메시지로 알린다.
- FR-6.2 진입 경로: 트레이 메뉴("메인 모니터 설정하기"), 창 바탕/타일 우클릭 메뉴(FR-2.7).
  - 대상 모니터 선택 UI 를 제공한다(연결된 모니터 목록에서 선택).
- FR-6.3 캡처 격자와의 연동: 주 모니터가 바뀌면 새 주 모니터를 캡처 대상에서 제외하고,
  이전 주 모니터는 캡처 타일로 편입되도록 격자를 재구성한다(FR-2.6 재구성 로직 재사용).
- FR-6.4 적용 실패 처리: ChangeDisplaySettingsEx 반환값이 성공이 아니면 변경 취소로 간주하고
  기존 배치를 유지, 사용자에게 원인(미지원/거부 등)을 안전하게 안내한다.

## 7. 트레이 아이콘 및 메뉴

- FR-7.1 트레이 아이콘 우클릭 메뉴 항목:
  - "정보 보기" : 개발자, 버전, 취급 주의 안내(화면 캡처 도구 특성) 등을 AboutForm 으로 표시.
  - "컨트롤창 띄우기" : 숨겨진 컨트롤창을 복원/포커스.
  - "메인 모니터 설정하기" : FR-6 동작 실행(대상 모니터 선택 후 OS 주 모니터 변경).
  - "백그라운드 캡처" (체크 항목) : 컨트롤창이 닫힌 상태에서의 캡처 on/off 토글. 기본 on.
  - "프로그램 종료" : 실제 프로세스 종료(트레이 아이콘 정리 후 Exit).
- FR-7.2 아이콘 더블클릭 시 컨트롤창 복원(FR-7.1의 컨트롤창 띄우기와 동일).
- FR-7.3 트레이 아이콘 상태 표시:
  - 캡처 동작 중(컨트롤창 표시 중 또는 백그라운드 캡처 on)이면 컬러 아이콘.
  - 백그라운드 캡처 off 상태이면 회색빛 아이콘으로 표시하여 정지 상태를 시각적으로 구분.

## 8. 창 닫기 동작

- FR-8.1 컨트롤창의 X(닫기) 클릭은 종료가 아니라 백그라운드 숨김(Hide)으로 처리한다.
  - FormClosing 에서 CloseReason 이 UserClosing 이면 e.Cancel = true 후 Hide.
- FR-8.2 실제 종료는 트레이 "프로그램 종료" 또는 명시적 종료 명령에서만 수행한다.
- FR-8.3 캡처 동작 정책(확정):
  - 컨트롤창이 표시(열림) 중이면 캡처는 항상 on 이다(트레이 토글과 무관하게 강제 on).
  - 컨트롤창이 숨김(닫힘) 상태이면 트레이 "백그라운드 캡처" 토글을 따른다(기본 on).
  - 백그라운드 캡처 off 이면 캡처 스레드를 일시정지하여 CPU 를 절감하고, 트레이 아이콘을
    회색빛으로 바꾼다(FR-7.3). 컨트롤창을 다시 열면 즉시 캡처를 재개한다.

## 9. 정보 보기(About) 내용

- FR-9.1 표시 항목: 프로그램명, 버전, 최종 수정일, 개발자/조직, 라이선스/사용범위.
- FR-9.2 취급 주의 문구: "본 프로그램은 화면을 실시간 캡처합니다. 민감 정보 노출에 주의하십시오. 캡처 영상은 로컬 메모리에만 존재하며 저장/전송하지 않습니다."

## 10. 설정 항목(요약)

- 캡처 FPS(기본 5), 클릭 표시 시간(기본 400ms), 백그라운드 캡처 on/off(기본 on).
- 저장 위치: %LOCALAPPDATA%\MultiMonitorCapture\settings.ini (사용자별, 쓰기 권한 안전).
- 형식: 단순 INI(키=값). BinaryFormatter 등 역직렬화 위험 방식 금지.
- 참고: 주 모니터는 OS 설정을 실제 변경(FR-6)하므로 앱 설정에 별도 저장하지 않는다
  (실행 시 OS 의 현재 주 모니터를 조회하여 캡처 제외 대상으로 사용).

## 11. 비기능 요구사항

- NFR-1 안정성: 24시간 연속 구동 시 핸들/메모리 증가 없음(자원 해제 검증).
- NFR-2 성능: 기본 FPS 에서 캡처로 인한 CPU 점유가 설비 작업을 방해하지 않는 수준.
- NFR-3 호환성: XP/10/11 동일 exe 동작. DPI 는 시스템 인식 수준으로 처리.
- NFR-4 격리성: 다른 프로그램의 창/입력/파일을 변경하지 않음(읽기 전용 화면 캡처).
- NFR-5 최소 권한: asInvoker, 네트워크 없음, 레지스트리/시스템 변경 없음(FR-6.2 예외는 확인 후).
- NFR-6 실패 안전: 캡처 실패 타일은 회색 처리 후 재시도, 전체 앱은 계속 동작.

## 12. 미결/확인 필요 항목

- Q1. (확정) FR-6: 트레이/우클릭에서 OS 주 모니터를 실제 변경(Windows 설정창과 동일 동작).
- Q2. (확정) 표시명 "멀티모니터캡처", 코드명 "MultiMonitorCapture". 개발자/조직 표기와 시작 버전(1.0.0 제안)은 배포 준비 시 확정.
- Q3. (확정) 캡처 기본 FPS = 5(200ms). 백그라운드 캡처 기본 on, 컨트롤창 표시 중 강제 on.
- Q4. (확정) 모니터 이름은 DeviceName 기본 표기. 사용자 별칭은 향후 확장.
